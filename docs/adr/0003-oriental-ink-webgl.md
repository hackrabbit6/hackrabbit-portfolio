# 全站改为东方水墨风格，并引入 Three.js 实时 3D 背景

## 背景

本人（站点所有者）在 2026-09-18 评审线上版本后给出判断：**当前视觉「没有自己的风格，整体样式没有吸引感」**，
要求重新设计，加入 3D 效果与本人喜欢的元素。经四轮决策确认：

1. 取向 = **东方 / 国风**；
2. 3D = **Three.js WebGL 实时 3D**（新增一个运行时依赖，已获本人授权）；
3. 范围 = **全站统一新风格**；
4. 版权 = **只用风格暗示**（配色 / 氛围 / 抽象母题），不使用任何受版权保护的角色立绘或 Logo。

## 决定

**全站视觉改为「墨韵 · 月下玉兔」东方水墨基调，并新增一层 Three.js 3D 背景；本决定取代 ADR 0002。**

ADR 0002 曾把首页定成「降技术味、面向非技术读者」、`/work/` 保留开发者审美，并明确写着
「未来若有人为了统一风格把首页改回……等于撤销本决定」。本次是所有者本人的显式改版要求，
因此 ADR 0002 的两套语气划分**正式作废**，全站统一到同一套东方水墨语言。

## 为什么可以加 Three.js

`AGENTS.md` 的硬边界是「不换技术」：不换框架、包管理器、部署平台，不引入 CSS 框架与组件库。
Three.js 三者都不是 —— 它是 WebGL 渲染库，作为**唯一新增运行时依赖**接入，且只用于装饰性背景层。
除它之外不引入任何 UI 库、动画库或状态库（GSAP 已在仓内）。

## 与 ADR 0001 的边界

ADR 0001 拆掉了电影感滚动层（Lenis 平滑滚动、`pin + scrub`），理由是招聘方会用触控板快速扫描，
滚动劫持对他们是阻力。**本次 3D 不违反该结论**：

- 3D 层是 `position: fixed/absolute` 的背景画布，`pointer-events: none`，不消费滚动距离；
- 不重新引入平滑滚动、不 re-enable `pin + scrub`；
- 只保留原有的四类进场动画，另加不阻断滚动的指针视差与卡片 3D 倾斜。

## 后果

- 色板、字体、母题、3D 场景的完整规范见 `docs/ORIENTAL-REDESIGN.md`。
- 全站看起来会与改版前完全不同；这是本决定的目的，不是回归。
- 性能预算、`prefers-reduced-motion`、无 WebGL 降级、移动端降级在 `ORIENTAL-REDESIGN.md` 中定义，视为验收条件。
- 角色、作品、履历、账号等**事实内容一个字不改**；本次只换视觉层。
