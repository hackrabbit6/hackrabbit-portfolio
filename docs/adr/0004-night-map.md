# 全站改为「兔子的夜间地图」：一张共用的 Three.js 3D 地图

## 背景

站主评审东方水墨版（ADR 0003）后，要求再做一版：更有辨识度、有 3D 效果和新颖的交互，
让访客一进来就被吸引，并能很快了解站主。经多轮方案对比，确认以下取向：

1. 母题 = 站主自己的元素：深夜、台灯、白兔化身（`public/avatar.webp`）、以及首屏那句「先看清地图，再动手」；
2. 3D = 整站共用一张 Three.js 实时 3D「夜间地图」，每个内容区块对应地图上的一个地标；
3. 范围 = 首页与全部子页面（`/work/`、全部案例页、`/services/`、`/writing/`）；
4. 滚动 = 页面保持原生长度，3D 地图不额外消耗滚动距离。

## 决定

**全站视觉由「墨韵 · 月下玉兔」改为「兔子的夜间地图」，本决定取代 ADR 0003 的视觉部分。**
完整规范见 `docs/NIGHT-MAP.md`。

- 3D 层从「首屏背景」升级为**全站固定背景**：`position: fixed`，所有页面共用同一个场景。
- 首页：读到哪个区块，镜头飞到对应地标，白兔化身跳过去等你。
- 子页面：镜头停在该页对应的地标，滚动时绕地标缓慢环视。
- 地标可以点：悬停高亮，点击跳到对应区块或页面（只在点到空白处时生效，不影响选字与链接）。

## 与 ADR 0001 的边界

ADR 0001 拆掉滚动劫持的理由（招聘方会快速扫页面）依然成立，本次**继续遵守**：

- 不引入平滑滚动库，不使用 `pin + scrub`，不为 3D 拉长任何区块；
- 镜头只**响应**原生滚动位置，不改变滚动本身；
- 3D 画布 `pointer-events: none`，不拦截任何点击、选择与滚动。

## 技术边界

- 继续只用仓内已有的 `three`，不新增依赖，不用 r3f。
- 不引入字体包，沿用系统字体栈。
- 事实内容（作品、履历、账号、价格、`Experience.tsx` 数据）一个字不改，本次只换视觉层。

## 后果

- 全站与水墨版完全不同；`ORIENTAL-REDESIGN.md` 只作为历史记录保留。
- 首页区块的标记 `data-map-stop` 是地图与内容的唯一对应关系，改区块顺序时要一起看地图。
- 降级路径（无 WebGL、减少动态效果、触摸设备）是验收条件，定义在 `NIGHT-MAP.md`。
