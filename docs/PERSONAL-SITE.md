# PERSONAL-SITE

站点由「个人作品站」改为「个人主页」。本文档描述这次改造。

先读 `AGENTS.md`（边界）与 `CONTEXT.md`（术语）。上一轮视觉整改见 `VISUAL-POLISH.md`
—— 那一轮的字号刻度、间距节奏、Cover 渲染管线、移动端与可访问性结论继续有效，不要推翻重做。

**严格按 phase 顺序做。** 每个 phase 结束跑 `bun run lint` 与 `bun run build`，全绿才进入下一个。

---

## 为什么改

原来的站只回答一个问题：「这个人交付过什么」。读者只有招聘方。

现在要同时回答三个问题，读者是两类人：

| 问题 | 谁在问 |
|---|---|
| 这个人是谁、在做什么 | 两类都问 |
| 去哪关注他 | 内容读者 |
| 他交付过什么、能不能雇 | 招聘方 |

**判断标准：一个从自媒体点进来的陌生人，能不能在首屏附近找到关注入口。**
现在不能 —— 站上唯一的联系方式是页脚 Contact 段的 email 和 GitHub。

---

## 路由集合

```
/                    个人主页
/now/                在做什么 / 在看什么 / 研究方向
/writing/            列表：站内长文 + 外链短内容混排
/writing/[slug]/     站内正文（Astro content collection）
/work/               完整作品集（保留现状）
/work/h5-game-sdk/   保留现状
/resume.pdf          保留
```

内容承载方式为**混合**：长文 / 技术笔记写在站内 markdown，短内容与视频外链到平台。
`/writing/` 列表把两种混排，外链条目标出平台名。

---

## 硬约束（未解除）

- **不得编造事实。** 账号、平台、书名、研究方向、工具用途，全部只能来自本人提供。找不到就不写这一块。
- **不得留占位文案。** 没有文章就不上 `/writing/`；没有 now 内容就不上 `/now/`。空页面比没有页面更差。
- **不得引入 CMS / 后端 / 评论 / 搜索。** 文章是仓库里的 `.md`，不是数据库。

## P0 — 事实订正

**这是最急的一步，因为站上现在写着假的东西。**

### P0.1 CREW 三行

`src/components/Crew.tsx` 的 `crew` 数组当前是：

```ts
{ agent: 'Claude Code',   role: '规划 / 大段重构 / code review' }
{ agent: 'Codex 桌面版',  role: '执行 / GUI / 截图 / 高频重复' }
{ agent: 'OpenSpec 工作流', role: '规范 / 边界 / 防跑偏' }   // ← 已不再使用
```

移除 OpenSpec，替换为 herdr。

> herdr 是终端里的 AI agent 多路复用器（Rust 单二进制，能识别每个 pane 内 agent
> 处于 working / blocked / done / idle）。**但它在本人流程里具体承担什么，必须由本人给出，
> 不得照搬工具官方描述。**

### P0.2 自媒体入口

首页需要一个「去哪关注我」的区块，位置在 Hero 之后、Selected Work 之前。
每个账号给出：平台、账号名、链接、这个号在讲什么（一句话）。

### P0 验收

- [ ] 站上不再出现已停用的工具
- [ ] 从首屏滚动不超过一屏能看到关注入口
- [ ] `bun run lint` / `bun run build` 绿

## P1 — 首页改为个人主页

### 目标结构

```
NAV
HERO                     你是谁
FIND ME                  自媒体账号入口          ← 新增
NOW（摘要）               一两行 + 链到 /now/
SELECTED WORK            降权：2–3 个精选 + 链到 /work/
EXPERIENCE               履历摘要（保留，不改数据）
CONTACT
```

### 规则

- Selected Work **不再是首页主角**，从当前占比约 46% 降到明显次要的位置。
  完整列表移到 `/work/`。这条与 `CONTEXT.md` 中 Selected Work 的现有定义冲突，
  执行本 phase 时**必须同步改掉那条术语定义**。
- `src/components/Experience.tsx` 的数据依然不许动（`AGENTS.md`）。
- 沿用 `VISUAL-POLISH.md` 定下的字号刻度与间距节奏，不要另起一套。

## P2 — `/now/`

now page 惯例：这一页回答「如果我们几个月没见，我最近在干什么」。

内容分区（每一区都需要本人提供真实内容，否则不上该区）：

- 现在在做什么
- 在看 / 在读什么
- 研究方向与在试的工具

首页 NOW 摘要与本页保持一致，改内容时两处同步。页面需标注最后更新日期。

---

## P3 — `/writing/`

列表页：站内文章与外链条目混排，倒序，外链标出平台名。
站内正文用 Astro content collection，文章是 `src/content/` 下的 `.md`。

**至少要有一篇真实文章才允许上线这个路由。**
