# PERSONAL-SITE

站点由「个人作品站」改为「个人主页」。本文档描述这次改造。

先读 `AGENTS.md`（边界）与 `CONTEXT.md`（术语）。上一轮视觉整改见 `VISUAL-POLISH.md`
—— 那一轮的字号刻度、间距节奏、Cover 渲染管线、移动端与可访问性结论继续有效，不要推翻重做。

**严格按 phase 顺序做。** 每个 phase 结束跑 `bun run lint` 与 `bun run build`，全绿才进入下一个。

---

## 为什么改

原来的站只回答一个问题：「这个人交付过什么」。读者只有招聘方。

现在要同时服务两类读者，而且他们**技术水平相差很远**：

| 读者 | 从哪来 | 想知道什么 |
|---|---|---|
| 内容读者 | 公众号 / 小红书 | 这人是谁、在做什么、去哪关注 |
| 招聘方与技术面试官 | 简历里的网址 | 能不能合作或雇佣 |

**判断标准：一个从自媒体点进来的非技术读者，能不能在首屏附近找到关注入口、并且看得懂首页在说什么。**

| 6 | 首屏语序：**现在 X。此前 4-5 年前端交付。** | 语序本身编码优先级 |
| 7 | Contact：**合作在前，全职在后** | 页尾与首屏口径一致 |
| 8 | **首页降技术味，`/work/` 保留开发者审美** | 见 `docs/adr/0002-two-visual-registers.md` |

## 硬约束（未解除）

- **不得编造事实。** 账号、平台、书名、研究方向、工具用途，全部只能来自本人提供。找不到就不写这一块。
- **不得留占位文案。** 没有内容就不上对应路由。空页面比没有页面更差。
- **不得引入 CMS / 后端 / 评论 / 搜索。** 文章是仓库里的 `.md`，不是数据库。
- **本仓库公开。** 不写个人隐私、求职策略、自身弱点分析或内容运营数据。

## P2 — `/writing/` —— 已完成（外链版）

`src/pages/writing/index.astro`，7 篇公众号长文，全部是真实永久链接。

两处刻意的取舍：

- **不列日期。** 公众号后台只对近一周显示「星期X」，其余是「07月20日」这类不含年份的格式，
  逐条推断会有猜的成分。宁可先不写，等确认后再补。
- **小红书 10 条没有逐条列出。** 它的卡片标题取的是正文首行，会被截断，
  照抄等于改写作者原文。所以小红书给主页入口，让读者自己去看。

第 5 项是唯一挡住 P1 的东西。本人有两套自我描述，方向不同：
两平台简介写的是「AI、产品、认知工具与个人系统实验」（我在玩什么，面向同类），
内容实际执行的是「帮普通人看懂 AI 时代里和自己有关的变化」（我为谁服务，面向普通读者）。
首屏那句 X 用哪个口径，会长出不同的站。

**2026-09-17 定稿：取「帮普通人看懂 AI 时代里和自己有关的变化」（面向普通读者）。**
理由：决定 8 要求首页降技术味，判断标准又是「非技术读者看得懂」——「认知工具 / 个人系统实验」
对普通人是黑话；技术可信度由决定 6 的后半句「此前 4-5 年前端交付」兜住。
关注入口简介原本用的另一套口径，已一并改成同一句，避免相邻两段语气打架。
