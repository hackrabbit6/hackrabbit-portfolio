# NIGHT-MAP ·「兔子的夜间地图」

全站视觉规范。依据 `docs/adr/0004-night-map.md`（取代 ADR 0003 的视觉部分）。
本文档只定义**视觉层**；作品、履历、账号、价格等事实内容不改。

## 概念

一张悬浮在深夜里的线条地形图。站主的化身（台灯下敲代码的白兔）是向导，
地图上每个地标对应站里的一块内容。首屏那句「先看清地图，再动手」从文案变成访客真实的体验。

整个世界只有黑、白、灰的细线；唯一的暖色是**台灯光**，唯一的冷色点缀是化身围巾上的**青色六边形徽章**。

面板透明度的上限写在 `src/styles/tokens.css` 的注释里：**0.45**。再高线框地图就整块被盖住，

台灯色按钮上的文字用 `#1A1208`。

## 字体

沿用系统字体栈，不引入字体包：

- `--font-display`：Georgia + 宋体系。标题、首屏名字（`hackrabbit` 用 Georgia 斜体）。
- `--font-body`：系统无衬线。
- `--font-mono`：系统等宽，只用于地图式的小标签（图例、比例尺、标注体）。

## 3D 场景（`src/lib/night-map.ts`，由 `NightMap.astro` 挂载）

- 画布：`alpha: true` + 透明清屏，夜色来自页面底色 —— 地图只是一层线，
  这样首屏标题的上半截才能画在 canvas 之下（见下方「排版与地图的耦合」）。
- 地形：等高线式的横向细线，地标周围压平。
- 地标：线框几何（`EdgesGeometry`），当前地标与悬停地标提亮。
- 化身：唯一的实体模型，按头像建模（大长耳、粉色内耳、深青眼睛、深色围巾 + 青色六边形徽章）。
  会跳到当前地标旁边，静止时头跟随指针、定时眨眼、耳朵轻摆。
- 台灯：暖色点光源 + 光晕，照亮工作台和化身。
- 镜头：首页按阅读位置在地标间飞行；子页面停在本页地标，按滚动进度绕行约 50°。

## 交互

- 指针视差：镜头随指针小幅偏移。
- 地标可点：悬停时出现提示，点击空白处跳转（首页滚到对应区块；子页面跳到对应页面或首页区块）。
  指针在文字、链接、图片、卡片上时不触发。
- 首页右侧固定「图例」（宽屏），列出全部地标并标出当前位置，可点击跳转；
  子页面左下角显示「你在 · 地标名」和比例尺。

## 排版与地图的耦合

上面那些定的是「地图怎么画」。这一节定的是**排版怎么跟地图发生关系** ——
早先只做了镜头联动，排版一行没改，结果就是「老站换了张壁纸」。

### 首屏：三层 + 标题分层

- 首屏只留三层：身份（`.eyebrow`）/ 名字（`.hero-title`）/ 一句自述 + **一个**主 CTA。
  自我介绍那句（现在在做什么）属于「在做什么」区块，不属首屏；次入口（GitHub）只做文字链接，
  不能有按钮的重量。
- 标题与 3D 分层：地形线从字形中间穿过（文字上半截在 3D 之下、下半截在上）。实现：
  - canvas 用 `alpha: true` + `setClearColor(NIGHT, 0)` 清屏，地图只是细线，夜色来自 `html` 背景；
    **canvas 一旦不透明，标题上半截就永远看不见，效果只剩「裁掉一半文字」**。
  - `Hero.astro` 把标题克隆一份到 `body` 顶层（`.hero-title-ghost`，`z-index: -1`，`aria-hidden`），
    按真实矩形贴在同一位置；正文标题用 `clip-path` 只露下半截，两条互补的斜线相交 3px 防接缝。
  - **切边必须是斜的**（`--title-split-left/right`，默认 `68% / 32%`）：水平切恰好对齐文本基线网格，
    第一眼会被读成「字被截断了」——像排版事故；斜过来才是一个明确的设计动作，
    而且让标题有了方向（左边沉进地形、右边站住）。切点只在这两个变量里调。
  - 夜色遮罩在标题处挖一个软边开口（`--band-x / --band-y / --band-rx / --band-ry`，
    由 `NightMap.astro` 按标题实际矩形写入），否则上半截会被压成灰、和下半截出现亮度台阶。
  - 只在 `.night-map[data-webgl='on']` 时裁切、才建克隆层 —— 没有 3D 时那就是缺字。
- 标题不做进场动画：`hero-rise` 只给下面几层，克隆层跟不上的话会出现闪烁。

### 标注体（取代圆角标题块）

- 每个区块标题前是一枚 `.map-mark`：`编号 · 地标名 · 方位`，`--font-mono`、`--fs-meta`、
  `letter-spacing: 0.06em`，1px `--panel-line` 细边 + 左边一条 `--accent` 竖边。
  编号与方位来自 `src/lib/map-stops.ts`，不要手写在页面里。
- 它取代了旧的 `.eyebrow` 圆角标签；只有首屏的 `.eyebrow`（身份）保留。
- 方位是 16 向罗盘，北 = 地图深处（`-z`），按 `night-map.ts` 的地标坐标算。

### 引线与地标钉

- 引线分两段：先从标注右端**水平**拉到正文栏右边界，再从那里**斜拉**到地标的屏幕投影。
  拐点必须在正文栏边界上 —— 单段斜线会横穿区块标题与正文。
- 端点是一枚 9px 小环（`.map-pin`），画在当前地标的投影点上；引线离小环留 12px。
- 只有**当前区段**亮引线；其他区段同时连线就不是标注，是一团网。
- 引线与地标钉都是纯装饰：`pointer-events: none`，不拦点击也不拦选字。
- 只在同时满足以下三条时渲染：3D 就绪、视口 ≥1100px、该区块在视口内。
  否则隐藏 —— 没有地图时引线指向空气，窄屏正文铺满整幅，引线只会穿过字。
- 子页面没有引线：正文是长文，引线无处可拐；只保留地标钉 + 左下角「你在 · 地标名」。

### 投影坐标的 CSS 变量

`night-map.ts` 暴露 `project(key)` 把地标世界坐标投到窗口像素，以及 `onFrame(cb)` 在相机
更新完成之后回调一次。投影不写到 `:root`（每帧改根变量会让整页样式失效），而是按元素写：

| 变量 | 写在哪 | 含义 |
|---|---|---|
| `--stop-x` / `--stop-y` | `.map-pin` | 当前地标的屏幕坐标（px） |
| `--leader-run` | 区块的 `.map-mark` | 水平段长度（到正文栏右边界） |
| `--leader-angle` | 同上 | 斜段角度（`rad`，水平向右为 0） |
| `--leader-length` | 同上 | 斜段长度（px，已减去端点空隙） |
| `--leader-opacity` | 同上 | 0/1，当前区段为 1 |

两个引线子元素从 `.map-mark` 继承这些变量。值变化小于 1px 时不重写。
布局（标注在哪、正文栏右边界在哪）只在滚动那一帧读一次，投影每帧算。

### 化身不许站到正文上

- 化身是全站唯一的亮实体。它一旦跟半透明面板重叠，面板下面就漏出一团白，像贴纸粘在字上
  （`/services/` 的「案例 · 站内 8 篇」是已知反例），这是「脏」不是「有特色」。
- 规则：着地点的屏幕投影必须落在**正文栏右边界 + 72px** 之外；越界时沿镜头右方向推回来。
  正文栏右边界由 `NightMap.astro` 的 `contentRight()` 量出来（子页面正文比首页窄，不能写死 token），
  窄屏返回 0 表示不约束（正文铺满整幅，地图本来就是背景）。
- 推的是**屏幕投影**，落点与跳跃路径都走同一个函数 —— 只约束落点的话，化身在半路会从卡片背后
  穿过去，那一瞬比落点压字还难看。地面地标推完重新贴地；工作台与台阶是作者摆好的高台，保持原高度。

### 阅读区退让

- 能力（`pillars`）、经历（`stairs`）、联系（`portal`）是纯阅读区：化身在这里缩到 **0.755**
  （基准 0.9），让视线落在字上。
- 其余地标保持基准：首屏、作品、AI 工具都是「看景」的段落，化身在那里的存在感是加分。
- 缩放逐帧插值、不跳变；`prefers-reduced-motion` 下直接呈现目标尺寸。

## 降级

- 无 WebGL / 脚本失败：显示静态夜色与网格背景，内容完整可读。
  此时不裁标题、不建克隆层、不挖夜色开口、不渲染引线与地标钉，标注体与面板照常。
- `webglcontextlost`（iOS Safari 会回收 context）：`preventDefault()` 后 `dispose()` 并移除 canvas，
  按「无 WebGL」降级 —— 不尝试重建，因为地图是全站固定背景，宁可变静态图也不要半死的层。
- `prefers-reduced-motion: reduce`：镜头直接切换，不飞行；化身不跳、不眨眼；无环境动画。
  引线与地标钉跟着最后一帧，仍然可读；首屏标题照样分层（分层不是动画）。
- 触摸设备：像素比 ≤ 1.25，地形线减半，关闭指针视差与悬停；视口 <1100px 时不渲染引线与地标钉。
- 标签页不可见时暂停渲染。

## 验收条件

- `bun run lint`、`bun run build` 全绿。
- 桌面、手机、减少动态效果、无 WebGL 四种路径都有完整呈现，无空白、无报错。
- 正文对比度满足 AA；导航、CTA、锚点跳转不受 3D 层影响。
- 3D 层不拦截指针事件，不消耗滚动距离。
- 首屏三层：1440 与 390 两个宽度都要一眼看出这不是普通落地页（地形线穿过标题）。
- 区块标注体只出现在区块标题前，编号与 `map-stops.ts` 一致；引线只在当前区段可见。
- 化身的落点在 1440 / 1280 / 390 三个宽度下都不与任何含文字的卡片重叠。
- 事实内容零改动。
